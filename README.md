# Acento Fino

Juego educativo de ortografía: **poner la tilde donde va, contra el reloj, y
descubrir en qué tipo de palabra me equivoco más.**

## 1. Nombre y descripción

Acento Fino es un juego en español donde aparece una palabra sin tilde y hay que
elegir, entre varias opciones, la escritura correcta antes de que se termine el
tiempo. Al final de cada partida muestra la puntuación, los aciertos, los errores
y **en qué categoría** (aguda, grave o llana, esdrújula o sobresdrújula) se
falló más, con una recomendación para practicar.

## 2. Funcionalidades y forma de uso

1. En la pantalla de inicio, tocar el botón **Comenzar**.
2. Aparece una palabra sin tilde y tres opciones: elegir la forma correcta.
3. Cada acierto suma puntos; cada error queda registrado.
4. La partida dura **60 segundos** o termina al responder **10 palabras**.
5. Al final se ven los resultados y la categoría a practicar.
6. El botón **Jugar de nuevo** empieza una partida nueva desde cero.

Requisitos: tener Node.js instalado.

```bash

npm install

# 2. Ejecutar en desarrollo (abre el navegador)
npm run dev

# 3. Ejecutar las pruebas automatizadas
npm test

# 4. Comprobar los tipos de TypeScript
npx tsc --noEmit

# 5. Compilar para producción
npm run build

# 6. Previsualizar la compilación de producción
npm run preview
```
